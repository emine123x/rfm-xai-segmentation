# RFM Customer Segmentation with XAI

Customer segmentation project using RFM (Recency, Frequency, Monetary) analysis, K-Means clustering and Explainable AI methods.

## Project Workflow

1. Exploratory data analysis
2. Data cleaning and preprocessing
3. RFM feature engineering
4. Feature transformation and scaling
5. K-Means clustering
6. Customer segment interpretation
7. Random Forest classification
8. SHAP-based model explanation

## Customer Segments

- VIP
- Regular
- Lost

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- SHAP
- Jupyter Notebook

## Project Structure

- `notebooks/` — analysis notebooks
- `src/` — reusable Python modules
- `data/` — raw and processed data
- `reports/` — generated outputs
